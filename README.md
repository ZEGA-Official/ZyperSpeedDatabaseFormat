# ZyperSpeedDatabaseFormat (ZSDF)

A tiny, ultra‑fast embedded database for Windows, written in C23.  
Replaces SQLite in resource‑constrained environments.

## Build
```bash
make          # builds libzsdf.a and zsdf.exe
make test     # runs unit tests
make bench    # performance benchmarks
```
